# Sudagene & GeneAcademy Project Management Skill

This skill provides the AI agent with the context and operational directives for Dr. Mohamed Gibbril's recurring workflows for the Sudagene / GeneAcademy SudaGene Platform.

## Core Responsibilities & Context
Mohamed manages a high cognitive load, overseeing daily project syncs, weekly team accountability audits, student telemetry tracking, and executive reporting. Whenever this skill is active, the agent must proactively assist in minimizing this operational burden.

## The Routine (Agent Directives)

### Daily Tasks
* **Master Project Updates (9:00 AM):** 
  * Assist in syncing all repositories, release zip packages, and project trackers.
  * Summarize overnight events, incoming admissions, or blockers.

### Weekly Tasks
* **72-Hour Team Sheet Audit (Sun & Wed, 9:00 AM):**
  * Check team sheets and logs for missing data or inactivity across core roles (GA-001, GA-004, GA-011).
  * Generate audit reminders.
* **Student Telemetry & Rankings (Mon & Fri, 11:00 AM):**
  * Parse student performance data across the 2,500 MTC™ clinical scenarios.
  * Update ranking boards, GP ledgers, and flag candidates needing intervention.
* **Executive Sync Briefs (Wed & Sat, 11:00 AM):**
  * Compile the week's telemetry, team sheet audits, and project syncs into a concise executive summary for leadership.

### Monthly Routine
* **End of Month Financial & Independent Credential Review:**
  * Reconcile Vodafone Cash and Bankak inflows against unit economic targets.
  * Audit SHA-256 SudaPass / GemIInIPass™ credential issues and B2B GLOMEt institutional pipelines.

## Execution Rules
1. **Anticipate the Schedule:** Check the current day of the week to anticipate which task Mohamed is working on based on the schedule above.
2. **Format for Executives:** When generating the Wednesday/Saturday briefs, use professional, high-level formatting (bullet points, clear blockers, verified metrics).
3. **Protect Cognitive Load:** Do not ask Mohamed redundant questions. Use existing context and repo state to draft updates first, then ask for his approval.
4. **Enforce Single Source of Truth (SSOT):** Ensure all numbers carry strict evidence standards, client-side storage remains zero-PII, and financial transactions are recorded in the central audit sheets.
